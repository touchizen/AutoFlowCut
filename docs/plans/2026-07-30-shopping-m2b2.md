# Shopping M2b-2 Implementation Plan

> **For Claude:** REQUIRED SUB-SKILL: Use superpowers:test-driven-development to implement this plan task-by-task.

**Goal:** Add honest DOM provenance support and expose shopping A/B review, scene-table review, and approval across IPC, preload, hook, and UI.

**Architecture:** Preserve `planMachine` as the main-owned authority and reuse the existing guarded shopping session/event pattern. Renderer code sends schema-shaped user decisions and draft/approval commands but never sends a replacement draft or approval hash; M3 remains responsible for renderer materialization acknowledgement.

**Tech Stack:** Electron IPC/contextBridge, React hooks/components, Vitest, Testing Library, Vite.
