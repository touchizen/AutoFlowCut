## 배경
M6b가 claude orchestrator를 sessionManager에 배선했다(mapper가 `agent:item-retracted` 이벤트를 내고, abort가 `sessionClosed`/`contextPreserved` 구조값을 반환, `agent:error`가 turn 실패를 알린다). renderer(ChatPanel)는 아직 이 세 계약을 소비 안 한다. M7a가 그 짝을 배선한다.

## 🔴 M7a 범위 (이것만)

### M7a-1. `agent:item-retracted` 이벤트 통과
- `electron/preload.js`: `onAgentEvent`의 valid allowlist(현재 `['agent:delta','agent:message','agent:tool-call','agent:usage','agent:done','agent:error']`, line ~172)에 **`'agent:item-retracted'` 추가**.
- `src/components/agent/ChatPanel.jsx:25` `AGENT_EVENTS` 배열에도 `'agent:item-retracted'` 추가.

### M7a-2. message/tool 엔트리에 provenance 저장 (retraction 전제)
현재 message 엔트리는 `{id,itemId,role,text,streaming}`이고 turnId/sourceUuids가 없다. retraction은 **turnId AND sourceUuid 교집합**으로만 지워야 하므로(§5.3 item4: `entry.turnId === payload.turnId && intersection(entry.sourceUuids, payload.sourceUuids)`) 엔트리에 provenance를 실어야 한다.
- **`appendDelta`**(`:449`): 현재 `(delta)`만 받는다. wire는 `agent:delta {delta,turnId,sourceUuid}`(§5.3). payload 전체를 받아 streaming bubble 엔트리에 `turnId`와 `sourceUuids`(Set→array, delta마다 uuid 누적, 중복 제거)를 저장. 핸들러(`:491`)도 `(payload) => appendDelta(payload)`로.
- **`finalizeMessage`**(`:462`): payload는 `{turnId, item:{id,text,sourceUuid,sdkMessageId}}`. 완성 엔트리에 `turnId`와 `sourceUuids`(기존 streaming bubble의 누적 + `item.sourceUuid` 합집합) 저장.
- **tool 핸들러**(`:493`): `agent:tool-call {turnId, phase, item}`. item에 `sourceUuids`(배열)가 있다(M6b mapper). toolCalls 엔트리에 `turnId`와 `item.sourceUuids` 저장.
- ⚠️ Codex/기존 wire는 turnId/sourceUuid가 **없을 수 있다**(codex delta는 문자열, `agent:message`의 codex item엔 sourceUuid 없음). 없으면 `turnId:null`, `sourceUuids:[]`로 두고 retraction이 그런 엔트리를 절대 안 지우게(교집합 빈 배열=no match) 한다. codex 회귀 없어야.

### M7a-3. `agent:item-retracted` 핸들러
payload `{turnId, sourceUuids}`. message 엔트리와 toolCall 엔트리 중 **`entry.turnId === payload.turnId && entry.sourceUuids가 payload.sourceUuids와 교집합 있음`**인 것만 제거.
- payload.turnId가 null이거나 sourceUuids가 비면 아무것도 안 지운다(UUID 전역 고유성 가정 금지, §5.3 item4).
- messages와 toolCalls 두 state 모두 필터.

### M7a-4. `agent:error`가 partial streaming 닫기
현재 `agent:error`(`:508`)는 `setRunning(false)+pushError`만. **모든 partial message의 `streaming:false`도 설정**(§8:577 "agent:error handler 자체가 모든 partial message의 streaming:false를 설정"). `agent:done`(`:504-507`)이 하는 `setMessages(current => current.map(m => ({...m, streaming:false})))`를 error에도. 순서/pushError는 유지.

### M7a-5. abort 결과의 sessionClosed/contextPreserved 처리
`abort()`(`:663-673`): 현재 result의 sessionClosed를 안 본다. M6b abort 구조값(§5.7):
- `result?.sessionClosed === true`(예: `abort-before-remote-start`/`abort-cancel-unconfirmed`/timeout/orphan-drain-close) → **`sessionOpenRef.current = false`** + status system 메시지 1회(`{id, role:'system', text: t('agent.sessionClosedAfterStop')}` 같은 신규 i18n 키; en/ko 양쪽 추가). `:572`의 `role:'system'` 패턴 참조.
- `sessionClosed`가 아니면(`contextPreserved:true`/`{aborted:false,reason:'idle'|'closing'}`) → 세션 유지(현행대로 ref 안 내림).
- 기존 `hasFailure(result)→pushError`, `finally setRunning(false)`, `abortEpochRef+=1`은 유지. timeout/failed(error+sessionClosed)면 pushError와 ref 내림이 함께 나야.

### M7a-6. forwarder `onDelta`가 Claude delta 객체 언팩
현재 `agent-api.js` `createAgentEventForwarder.onDelta(delta) { emit('agent:delta', { delta }) }`(`:238-240`)는 언팩을 안 한다. M6b mapper는 codex엔 **string**, claude엔 **`{text,turnId,sourceUuid}` 객체**를 onDelta로 보낸다(§5.3: "forwarder는 Codex의 기존 string delta도 계속 받아 {delta}로 내보내고, Claude object에는 optional turnId/sourceUuid를 보존한다"). 그대로 두면 renderer가 `{delta:{...}}`를 `String()`해 "[object Object]"가 된다.
→ onDelta가 분기: string이면 `emit('agent:delta',{delta})`(turnId/sourceUuid 없음), 객체면 `emit('agent:delta',{delta:obj.text, turnId:obj.turnId, sourceUuid:obj.sourceUuid})`. ChatPanel appendDelta(M7a-2)가 이 provenance를 받는다.
