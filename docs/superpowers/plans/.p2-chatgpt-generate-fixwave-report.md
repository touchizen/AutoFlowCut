## What changed

- `buildImagePrompt` now emits one physical line and collapses scene CR/LF whitespace to one space. A Korean prompt stays on the measured `execCommand` path instead of falling into the non-ASCII trusted-input refusal, and the wrapper cannot phantom-submit a preamble through a typed Enter.
- Estuary logs now contain only origin/error-name metadata. Content IDs, dimensions, counts, URLs, signatures, prompts, and page text are absent. Non-exception state-machine failures log their constant detail as `errorName`.
- Custom thumbnail definitions are treated as text output definitions, not image references. Actual image references remain refused.
- Reference validation is fail-closed in renderer engine, IPC, and adapter: only absent/null or an actual empty array is accepted.
- A generation is bound to its admitted `{mode, sessionTarget, route revision, target}`. IPC hands an admitted request directly to the cancellable adapter and rechecks the route after adapter submission; observe/collect refuse an ID after any route-revision change.
- ChatGPT jobs own an `AbortController` before their first session probe. Stop and route quiesce cancel queued/running session waits, page work, and authenticated fetch/body reads; fetch/body timeouts abort their underlying signal. Flow/API keep their existing stop behavior.
- `batchCount !== 1`, any explicit `aspectRatio`, and any explicit `seed` fail before composer submission with stable, honest unmeasured-option errors. No aspect/seed support was fabricated.
- The spike's two-streak/re-check, sticky submitted acknowledgement, and once-only Enter fallback tests were ported with event-log assertions.

## What the user sees for a Korean scene

The Korean scene is now wrapped as a single line, so it no longer deterministically fails as `non-ascii-fallback-unmeasured` and cannot type a newline that submits a half prompt. On the measured request shape (`batchCount: 1`, no aspect ratio, no seed), ChatGPT receives the full Korean prompt once and the adapter waits for the same estuary ID on two consecutive polls before saving it.

The current normal project Start path explicitly sends its project aspect ratio (normally `16:9`, and often a locked seed). Therefore pressing **생성 시작** currently stops before touching the composer and the scene shows the honest error `ChatGPT aspect ratio control is not measured, so this request was not submitted.` It no longer reports a clean success with a silently square image. If aspect is absent but a seed is present, the equivalent seed-unmeasured error is shown.
