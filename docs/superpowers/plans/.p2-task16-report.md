## Brief 대비 보강/편차

- `electron/main.js`에 Task 10 전용 explicit awaited no-op `routeSessionJobs` owner를 실제 production controller에 주입했다. brief의 required port를 shipped path에서 만족하려면 필요한 wiring이다.
- `ModeToggle`, `ModeGate`, `ModeSelector`를 추가 수정했다. 실제 제품 mode 선택 경로가 context/storage를 main 성공 전에 바꾸는 선커밋을 막고 모든 shipped 선택을 canonical route transaction으로 보내기 위한 보강이다. ChatGPT 선택 UI는 추가하지 않았다.
- 신규 테스트 파일 안에 production owner 주입, omitted-port rejection, missing-sender fail-closed, 실제 `ModeToggle`, production `useRouteQuiesceBridge`에 대한 positive/negative control을 추가했다.
- 변경 금지된 기존 `App.chatgptTargetGate.test.jsx`와 full-suite 호환을 위해 `App`에 이름을 계산하는 legacy `setMode` fallback이 남아 있다. 이 경로는 canonical preload가 없는 이전 preload/HMR 창에서 `api` 또는 `flow+flow`만 표현하고 target 전환은 fail closed한다. 현재 packaged preload는 항상 `setRoute`를 제공하므로 shipped modern path는 이 fallback에 도달하지 않는다.
- 수정 금지된 P1 controller 테스트는 sender 없는 fake IPC event와 omitted options를 사용한다. 이를 변경하지 않으면서 production omission을 금지하기 위해, direct/real IPC에서 omitted `sessionJobs`는 detach 전에 `route-session-jobs-required`로 실패하고 sender 없는 legacy IPC harness에만 별도 명시 no-op owner를 전달한다.
