## Implemented changes

- F1: transport/API-unavailable failures no longer fabricate a renderer-authored route. Boot reconciliation commits only a parseable route received in the result; otherwise it returns the transport failure without a route or commit. The production `invokeMainRoute` wrapper also stopped echoing renderer state.
- F2: ChatGPT reconnect captures a commit-time route version and request sequence, then verifies mount, route version, mode, target, sequence, and any main-returned route after the route await and again after the reconnect await.
- F3: all five R1 shortcuts are attempted. Any false return or throw triggers best-effort unregister of every shortcut acquired by that registration attempt before `{registered:false}` is returned.
- F4: the runtime-authored adapter contract is `getSafetyCeilingBytes`, `observeSurface`, `executeCase`, `reviewCase`, and `finalize`. Only a local filesystem module is loadable; URL modules are rejected. The runner passes the live `executeJavaScript`/`sendInputEvent`/`capturePage` ports plus real fixture bytes and exact padded PNG ladder to that adapter. Runtime events are sanitized and redirect evidence is reduced to origins before report output.

## Deliberate non-fix

The empirical R1 runtime adapter itself was not written and the R1 measurement/result document was not generated. Its mechanism, selectors, attach-ready/error predicates, operator outcome, limits, login/session signals, and redirect origins cannot be known before the human-authenticated runtime measurement. Providing a default would fabricate precisely the facts R1 exists to discover. The executable orchestration and local adapter port are now real; until an operator supplies an observed adapter via `AUTOFLOWCUT_R1_RUNTIME_MODULE`, the spike fails closed and explicitly reports the missing methods.
