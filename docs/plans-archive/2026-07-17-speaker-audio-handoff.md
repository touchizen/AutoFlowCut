## ⚠️ 다음 사람이 알아야 할 함정

- **`npm run test:run`은 실패해도 exit 0.** 숫자를 직접 봐라. 오늘 파일 하나가 파싱 에러로 통째로 안 돌았는데("no tests") 총계가 464→459로 조용히 줄었을 뿐이었다.
- **`cutAudio`는 겹치는 range를 throw한다.** stepMachine 테스트는 cutAudio를 목으로 주는데 **그 목은 겹침 검사를 안 한다** — widen 폴백이 크래시하던 걸 6240개 초록불이 못 잡은 이유.
- **`isNarratorTrackSpeaker('')`는 true다** (화자 미지정 = 나레이터). 빈/공백 참조를 그대로 넘기면 전원이 나레이터가 된다.
- **`start()`는 접수가 아니라 완료 promise다.** LLM 응답+검수+저장까지 기다린다.
- **progressLog는 메모리고 `start()`마다 지워진다.** 전체 실행은 audio done 직후 prompts를 시작하므로 경고가 몇 초 만에 사라진다 → 그래서 `approx`/`needsReview`를 세그먼트에 영속한다.
- **`store.load()`/`loadText()`는 읽기·파싱 실패를 조용히 삼킨다.** state를 못 믿는데 'pending'을 위조하면 무음 export가 샌다 → `loadTextStrict` + 명시적 파싱.
