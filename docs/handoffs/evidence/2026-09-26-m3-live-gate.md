## 3. 결함 아님 · 기록만 (후속 후보)

1. `flow:new-project` 1회 실패(생성 rpc 없음) — 재현 안 됨. 다시 나오면 창 크기·홈 로드 시점을 계측.
2. 채택 모달이 그 Flow 프로젝트가 **다른 앱 프로젝트의 것**이라는 걸 알리지 않는다(`test` ↔ `m3-live-gate` 공유가 여기서 생김).
3. MCP `app_generate_scene` 은 준비 가드에 막혀도 "triggered" 만 — 에이전트가 실패를 모른다.
4. 영상 탭 번호는 목록 순서(`index + 1`) — 3번째 씬의 영상이 "1번"으로 보인다.
5. CSV 가 영상 프롬프트를 바꿔도 옛 영상이 `complete` 로 남는다 — 앱 전체 정책(UI 편집·parseFromCSV 동일). 스토리 반영의 `staleVideo` 는 아무도 안 읽는다.
6. CSV 재적용은 이미지 `status:'error'` 는 남기고 오류 문구(`error`·`errorKind`)는 버린다(분류에 안 쓰여 표시만 빈다).
7. 클립보드: Safari·Word 에서 온 HTML 은 복원 뒤 앞에 meta 한 겹이 생긴다(Electron write 가 붙인다, 피할 수 없음) · PDF 만 복사된 경우 PNG 로 돌아올 수 있음(리뷰어 추론, 이번 변경 전부터).
8. 에이전트 채팅 창 DOM 은 새 flow.google.com 에서 미관측(채팅 rpc 는 있음) — 덤프를 확보하면 `닫기` 라벨 폴백도 구조 앵커로.
